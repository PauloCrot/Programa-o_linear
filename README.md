# Otimização Linear - Pesquisa Operacional

Resolução computacional de uma lista com 12 problemas de Programação Linear formulados matematicamente e solucionados em Python com a biblioteca **PuLP** e o solver **CBC**.

---

## Tecnologias Utilizadas

* **Linguagem:** Python 3.12+
* **Biblioteca de Otimização:** [PuLP](https://coin-or.github.io/pulp/)
* **Solver:** COIN-OR CBC (integrado ao PuLP)
