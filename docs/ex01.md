# Exercício 1: Composição de Ração

O objetivo é produzir 10.000 kg de ração com o menor custo possível, satisfazendo exigências nutricionais de proteína, fibra, calorias e limites de proporção de ingredientes.

### Variáveis de Decisão
* $x_1$: Quantidade de Cevada (kg)
* $x_2$: Quantidade de Aveia (kg)
* $x_3$: Quantidade de Soja (kg)
* $x_4$: Quantidade de Milho (kg)

### Função Objetivo
Minimizar o custo total dos insumos:

$$
\min Z = 30x_1 + 48x_2 + 44x_3 + 56x_4
$$

### Restrições

* **Produção total necessária:**
  $$x_1 + x_2 + x_3 + x_4 = 10000$$

* **Teor mínimo de proteína ($\ge 15\%$):**
  $$6{,}9x_1 + 8{,}5x_2 + 9{,}0x_3 + 27{,}1x_4 \ge 150000$$

* **Teor mínimo de fibra ($\ge 8\%$):**
  $$6x_1 + 11x_2 + 11x_3 + 14x_4 \ge 80000$$

* **Calorias mínimas ($1.100\text{ kcal/kg}$):**
  $$1760x_1 + 1700x_2 + 1056x_3 + 1400x_4 \ge 11000000$$

* **Calorias máximas ($2.250\text{ kcal/kg}$):**
  $$1760x_1 + 1700x_2 + 1056x_3 + 1400x_4 \le 22500000$$

* **Mínimo de Milho ($20\%$ do total):**
  $$x_4 \ge 2000$$

* **Máximo de Soja ($12\%$ do total):**
  $$x_3 \le 1200$$

* **Não-negatividade:**
  $$x_1, x_2, x_3, x_4 \ge 0$$
