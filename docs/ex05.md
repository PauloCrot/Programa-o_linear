# Exercício 5: Uso de Capacidade Ociosa

O objetivo é maximizar o lucro da produção de três tamanhos de produtos (Grande, Médio e Pequeno) distribuídos entre três fábricas. O modelo deve respeitar capacidades de produção, limitações de área física de estocagem, demanda de mercado e garantir que o percentual de uso da capacidade ociosa seja uniforme entre as três fábricas.

### Variáveis de Decisão

Seja $x_{ij}$ a quantidade do produto de tamanho $j$ ($G, M, P$) produzida na fábrica $i$ ($1, 2, 3$). Ex: $x_{1G}$ é a quantidade de produto Grande na Fábrica 1.

### Função Objetivo

Maximizar o lucro total:

$$
\max Z = 12(x_{1G} + x_{2G} + x_{3G}) + 10(x_{1M} + x_{2M} + x_{3M}) + 9(x_{1P} + x_{2P} + x_{3P})
$$

### Restrições

- **Capacidade Máxima de Produção (unidades):**
  - Fábrica 1: $x_{1G} + x_{1M} + x_{1P} \le 500$
  - Fábrica 2: $x_{2G} + x_{2M} + x_{2P} \le 600$
  - Fábrica 3: $x_{3G} + x_{3M} + x_{3P} \le 300$

- **Espaço Máximo de Estocagem ($m^2$):**
  - Fábrica 1: $20x_{1G} + 15x_{1M} + 12x_{1P} \le 9000$
  - Fábrica 2: $20x_{2G} + 15x_{2M} + 12x_{2P} \le 8000$
  - Fábrica 3: $20x_{3G} + 15x_{3M} + 12x_{3P} \le 3500$

- **Demanda de Mercado (Vendas):**
  - Grande: $x_{1G} + x_{2G} + x_{3G} \le 600$
  - Médio: $x_{1M} + x_{2M} + x_{3M} \le 800$
  - Pequeno: $x_{1P} + x_{2P} + x_{3P} \le 500$

- **Uniformidade de Produção (Mesmo % de uso entre fábricas):**
  - F1 e F2: $6(x_{1G} + x_{1M} + x_{1P}) - 5(x_{2G} + x_{2M} + x_{2P}) = 0$
  - F2 e F3: $1(x_{2G} + x_{2M} + x_{2P}) - 2(x_{3G} + x_{3M} + x_{3P}) = 0$

- **Não-negatividade:**
  $$x_{ij} \ge 0$$
